MinimalSF Extended adds power-user actions to the long press menu of the <b>MinimalSF</b> launcher, without making the launcher itself any bigger. Install it, and "extended…" appears when you long press an app.

<b>Actions</b><ul><li><b>Open in freeform:</b> open the app in a floating window</li><li><b>Force stop:</b> close the app completely</li><li><b>Clear cache:</b> delete the app's temporary files (needs Shizuku started with root)</li><li><b>Clear data:</b> reset the app like a fresh install, after asking you</li><li><b>Freeze:</b> disable the app without uninstalling it; unfreeze it from this app's screen</li></ul><b>How it works</b><ul><li>The actions run through <b>Shizuku</b>, which you install and start yourself (wireless debugging or root), then allow for this app</li><li>Only MinimalSF can use it: it only accepts requests from apps signed with the same key</li><li>It never touches the system, Shizuku or MinimalSF itself</li></ul><b>Private</b><ul><li>No internet permission, no ads, no tracking</li><li>About 50 KB</li></ul>Needs the MinimalSF launcher (1.3.2 or newer) and Shizuku.
